## 📞 Support Information

### If Something Doesn't Work

1. **Check logs** - Terminal where Django is running
2. **Refresh page** - Press F5 to reload
3. **Clear cache** - Ctrl+Shift+Delete
4. **Restart server** - Kill and restart Django
5. **Read docs** - Check TROUBLESHOOTING_FIXES.md

### Common Issues & Fixes

**Issue:** Login fails  
**Fix:** Use correct credentials (testadmin/testpass123)

**Issue:** No results  
**Fix:** Try simpler query or check database has data

**Issue:** Slow response  
**Fix:** Restart server, it may be caching

**Issue:** Page not loading  
**Fix:** Make sure Django server is running
